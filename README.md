# dotoscope · ежедневный пазл

Ежедневный пазл «соедини точки» для Telegram Mini App от лаборатории
**ROUND THINGS INC**. Плата 6×6, пять цветов: проводишь цепочку из двух и
более соседних одноцветных точек — они гаснут, верхние падают вниз, сверху
досыпаются новые.

- **Вызов дня** — одна плата на всех (сид = дата UTC), 25 ходов, одна
  рейтинговая попытка в день, цель дня ×1.5.
- **Свободно** — случайный сид, попыток сколько угодно, без рейтинга.

Визуальный язык — от основного прибора dotoscope (ветка `dottony`): чёрное
стекло, оранжевый акцент `#e84b23`, Inter + JetBrains Mono.

## Структура

```
packages/engine        движок: чистый TypeScript, без DOM, общий для клиента и сервера
  src/rng.ts           mulberry32 с явным состоянием, хеш строки в сид
  src/config.ts        все числа: размеры, лимит ходов, формула очков, список целей
  src/board.ts         заполнение, гравитация и досыпка, поиск хода, перемешивание
  src/game.ts          состояние партии, проверка и применение хода
  src/goals.ts         выбор цели по сиду, прогресс, итог с множителем
  src/daily.ts         сид и номер дня по UTC
  src/replay.ts        реплей журнала ходов — им сервер считает очки сам
apps/web               клиент: Vite + TS без фреймворков
  src/plate.ts         плата на канвасе: дорожки, точки, падение, ввод свайпом
  src/telegram.ts      WebApp SDK: ready/expand, тема, HapticFeedback, BackButton; вне Telegram — лаборант
  src/store.ts         местная память попытки дня и стрик (пока нет сервера)
  src/main.ts          экраны: меню, игра, итог
apps/server            этап 3: Fastify + Postgres (drizzle), initData, /daily, /submit, таблица
docker-compose.yml     этап 3: Postgres
.env.example           этап 3: BOT_TOKEN, DATABASE_URL
```

## Правила движка

- **Один поток.** Стартовая плата, вся досыпка и перемешивание тупика идут
  из одного PRNG от сида. Одинаковые ходы на одном сиде дают одинаковую
  плату и счёт — на этом стоит античит.
- **Порядок досыпки** зафиксирован: столбцы слева направо, в столбце новые
  точки сверху вниз. Менять нельзя — сломаются сохранённые реплеи.
- **Цель дня** выбирается отдельным розыгрышем от хеша сида, а не из потока
  платы: правка списка целей не меняет саму плату.
- **Очки:** `10 · n(n−1)/2` за цепочку из `n` — шесть точек стоят 150, три
  пары по две — 30. Формула и коэффициенты — в `config.ts`.
- **Ход** — массив клеток `[строка, столбец]` в порядке проведения.
  Негодный ход (несоседние, разные цвета, повтор, за краем, сверх лимита)
  отклоняет весь журнал.

## Команды

```bash
pnpm install
pnpm dev         # клиент на http://localhost:5173 (и в сети — для телефона)
pnpm test        # тесты движка (vitest)
pnpm typecheck   # проверка типов
```

Без Telegram клиент работает в режиме разработки: игрок — «Лаборант»,
haptic и «Назад» молчат. Попытка дня пока хранится в localStorage —
сбросить её: DevTools → Application → Local Storage → `dotoscope-daily-*`.
